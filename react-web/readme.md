# Web Tienda de Teléfonos

> Una tienda online moderna de smartphones desarrollada con React, con el diseño anterior hecho en html.

---

## Demo

🔗 [Ver diseño online](https://web-tienda-telefonos.pages.dev/)

---

## Descripción

Este proyecto es una aplicación web de e-commerce enfocada en la venta de teléfonos móviles.  
Está diseñada con una estética moderna y minimalista, priorizando la experiencia del usuario.

---

##  Características

-  Catálogo de productos
-  Diseño responsive
-  Carga rápida
-  UI moderna (blanco/negro)

---

## Tecnologías

- 🎨 Boostrap/CSS3
- 🌐 HTML5
- 💡 JavaScript

---

## 📦 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/perejilinformatico/web-tienda-telefonos.git

# Entrar a la carpeta
cd web-tienda-telefonos

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev
